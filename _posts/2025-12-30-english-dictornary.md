# 第1课

## ag

**Proto-Indo-European root meaning "to drive, draw out or forth, move."=do, act, 可表示“做、驱动、代理做”**

---

### agency
*   **词性/释义:** n. 代理(处)；代办处；政府专门机构，政府内的局，部，处
*   **词源解析:** (ag做；代理；引导 + ency表示机构或状态 → 代理机构)

### agenda
*   **词性/释义:** n. 议事日程，待议事项，记事册
*   **词源解析:** (ag做；代理；引导 + enda表示名词复数 → 做的事情 → 议程)

### agent
*   **词性/释义:** n. 代理人；代理商；（艺术界的）经纪人
*   **词源解析:** (ag做；代理；引导 + ent表人或物 → 做的人 → 代理人)

### coagent
*   **词性/释义:** n. 合作者；帮手；伙伴
*   **词源解析:** (co共同 + agent → 共同做的人)

### agitate
*   **词性/释义:** v. 煽动，鼓动，抗议；使焦虑；搅动（液体等）
*   **词源解析:** (ag驱使 + it它 + ate动… → 鼓动)

### agitation
*   **词性/释义:** n. 焦虑不安；煽动，鼓动；（液体的）搅动
*   **词源解析:** (agitate电子 + ion名词)

### agitator
*   **词性/释义:** n. 鼓动者，煽动者；搅拌器
*   **词源解析:** (agitate + or人 → 鼓动的人)

### agitating
*   **词性/释义:** adj. 搅拌的，搅动的；不安的；鼓动的
*   **词源解析:** (agitate + ing形容词)

### agony
*   **词性/释义:** n. (精神或肉体的)极大痛苦，创伤；痛楚，苦难
*   **词源解析:** (agon=struggle挣扎，斗争 + y构成名词：表“状态，性质” → 痛苦)


# 第2课

## act
> **"a thing done," from Latin actus "a doing; a driving, impulse, a setting in motion; a part in a play." = 做，驱动**

*   **act** v.表演，扮演；起作用，见行动，举止，表现
> ( act做。事做 → ing由动词变名词动作成为→表演 )

*   **acting** n. (戏剧、电影)表演；演艺；adj.表演的；行动，行为
> ( act做。事做 → ing由动词变名词动作成为→表演 )

*   **action** n.行动，动作；作用；运转;行为；战斗
> ( act做 → ing由动词变名词动作成为→表演 )

*   **active** adj.积极的，活跃的；（尤指体力上)忙碌的
> ( act做 → ing由动词变名词动作成为→表演 )

*   **activate** v.启动，激活；驱动，驱使
> ( act + ivate使... → 使...活动 )

*   **activity** n.通讯状况；活跃；活动
> ( act + ivity状态 → 活动状态 )

*   **inactivity** n.不活跃；不做任何事，不活动
> ( in不 + activity活动 )

*   **actor** n.男演员，演员，行动者；擅长演戏的人

*   **actress** n.女演员

*   **actual** adj.真实的，现实的，直觉的，目前的
> ( act动作 + ual有...性质的，属于...的 → 行动的 → 真实的 )

*   **actualize** v.实现；使发生，实施，实行
> ( actual真实的 + ize使... → 实现化 → 实现 )

*   **enact** v.制定，通过，颁布（法令）；扮演，表演
> ( en + act → 使（法律）动 → 实施法律 )

*   **exact** adj.确切的，精确的；严厉的；一丝不苟的 v.强取，勒索；实施（报复）
> ( ex出 + act → 把[事实]驱述出来 → 提取 )

*   **exacting** adj.严格的，苛求的；吃力的 v.逼取；急需
> ( exact + ing )

*   **interact** v.相互交流，互动，相互作用，相互影响
> ( inter相互 + act → 相互动 → 相互作用 )

*   **react** v.（作出）反应，起化学反应；(对食物等) 不良反应；(和惯性地) 回顾
> ( re反 + act → 反动；反应 )

*   **transact** v.做交易；办理；谈判；处理
> ( trans越 + act → 横向动 → 互相贸易成交是 )

*   **counteract** v.抵制，抵抗；抵消
> ( counter反 + act → 反着动 → 力量相互抵 → 抵消 )

## audi

*   **centigrade** adj. / n.摄氏温度计(的)；百分度的
> ( from centi- "hundred"+ second element from Latin gradi " to walk, go, step" )

*   **centimeter** n.厘米

*   **concentrate** v. / n. (使)集中注意力；集结/会师，专心；浓缩；n.浓缩物

## claim, clam

*   **claim** v.声称，断言，索要，提出，要求；权利
